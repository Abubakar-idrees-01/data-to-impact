How this was measured

Judge: an LLM over an OpenAI-compatible API (Groq free tier), temperature 0, JSON output, every response cached. Data: a balanced, seeded sample of RAGTruth (dev split for tuning, test split for the final number; ids in datasets/ragtruth_ids.json). Agreement: Cohen's kappa, precision/recall/F1 for the "hallucinated" class, 95% bootstrap intervals. Code: 02-llm-evals (Python standard library only).
