## Structure

Each project lives in its own folder with:

```
project-name/
├── README.md        # problem, approach, results, how to run
├── data/            # small samples only (raw data is gitignored)
├── notebooks/       # exploration & analysis
├── src/             # reusable code
├── models/          # saved models (gitignored)
└── requirements.txt
```
