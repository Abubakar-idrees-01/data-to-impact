Scout: an AI agent, replayed step by step

Real runs of a research and developer agent built from scratch (project 4 of data-to-impact). Each card is one model call or tool call, with what came back and what it cost. Some runs failed: each failure led to a fix, described with the run. Everything outward needs a human "yes". Code and docs.

Traces are recorded by the agent itself (.scout/traces/*.jsonl); page texts are shown as the model saw them, shortened. Account identifiers are removed. Built by scripts/build_site.py.
